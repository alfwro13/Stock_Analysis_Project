{% endif %} {# ── Methodology note ── #}

How this works: Tracks the actual top-10 SMGB.L semiconductor holdings (MU, AMD, AVGO, ASML, INTC, TSM, NVDA, LRCX, AMAT, TXN). After the LSE closes at 16:30 BST, US markets continue trading for another 4½ hours — the tool uses those live post-close moves as the primary signal. The Holdings model computes a weighted sum of each constituent's return using the known ETF weights (live holdings from yfinance where available), then applies a GBPUSD FX adjustment. In parallel, a 60-day OLS regression provides a 95% confidence interval. All prices are in GBP (£). Prediction is for the next UK trading morning (Monday if today is Friday).
