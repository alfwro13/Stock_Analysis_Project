📈 Pattern Detection

Scans your portfolio and watchlist once per day for chart patterns using rolling-window swing detection plus volume confirmation, RSI divergence, and a required prior trend. Covers Head & Shoulders / Inverse Head & Shoulders, Double Top / Double Bottom, Bull Flag / Bear Flag, Bull Pennant / Bear Pennant, Ascending Triangle / Descending Triangle / Symmetrical Triangle, Rising Wedge / Falling Wedge, Volatility Squeeze, NR4 / NR7 Narrow Range, Parabolic Stretch, Bullish / Bearish Divergence, and Micro-Structure Candlestick Triggers. Results appear at the Pattern Detection tools page.
