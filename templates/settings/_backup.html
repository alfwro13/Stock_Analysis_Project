⚠️ One-time server setup required — the app needs passwordless sudo rights to mount NFS shares. Run tools/setup_nfs_backup.sh on the host that runs the app (not via sudo — it asks for your password itself), or see Glossary → Technical Documentation → NFS Backup Setup for the manual steps. ♻️ Recovery

Restoring overwrites the live database, data files, and models with the contents of the selected archive, after checking it against the SHA-256 recorded when it was created. It is refused while a job is running; wait for it to finish first. Restart the service afterward so every in-memory cache reloads the restored data.
